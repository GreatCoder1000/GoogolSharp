# 🎓 What is Googology?

Googoology is the study of naming, analysing, and increasing large numbers. It's antithesis, *ultrafinitism*, is the assumption of the (completely wrong) statement that "numbers end", or more precisely, the number of finite numbers is a finite number.

## ❓ What's the point?

No point 🤣

## 😉 Isn't the point to make the largest number?

Kinda 🤔. But just adding one or repeating the same operation multiple times is not allowed. That's cheating. We call that a "naive extension".

## 🤔 Then what's the point?

Make new number systems in which you spawn a "god number" that is the culmination of using the (probably complicated) "number system".

## 😇 Isn't Googology this random whimsical study which is not at all serious?

Absolutely NOT! (Well, you could make it the whimsical study by creating random names like *Arborcity* , *hsgfgjkshgk*, etc. but that's called **Whimsy Googology**) If you think stuff is always wrong in Googology and it doesn't make sense, enter **Pataphysical Googology** which means googology that doesn't make sense (Read this wonderful article by a truly serious googologist about some truly pataphysical googology [here](https://sites.google.com/site/largenumbers/home/3-2/andre-joyce)). If you think Googology is just playing around with infinities in a "wrong way", enter **Fictional Googology** (click [this link](https://fictional-googology.fandom.com/) for more info). If you believe googology is actually something great, that's true googology.
